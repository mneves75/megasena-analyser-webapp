## Lessons / mistakes

- `rsync` include order matters: explicit standalone includes must come before global `.next/`/`node_modules/` excludes, otherwise the standalone build is stripped and Next.js crashes with “Could not find a production build”.
- SQLite “readonly database” after a deploy usually means the *directory* is not writable by the container user, not the file itself. The `bun` user in `oven/bun:canary-alpine` is UID 1000; on this host `ubuntu` is also UID 1000, so `chown -R ubuntu:ubuntu db logs` fixes it.
- Accidentally overwrote the server’s production compose with the local dev compose; keep deployment-repo compose separate and verify after rsync.
