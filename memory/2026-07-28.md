## Lessons / mistakes

- `rsync` include order matters: explicit standalone includes must come before global `.next/`/`node_modules/` excludes, otherwise the standalone build is stripped and Next.js crashes with “Could not find a production build”.
- SQLite “readonly database” after a deploy usually means the *directory* is not writable by the container user, not the file itself. The `bun` user in `oven/bun:canary-alpine` is UID 1000; on this host `ubuntu` is also UID 1000, so `chown -R ubuntu:ubuntu db logs` fixes it.
- Accidentally overwrote the server’s production compose with the local dev compose; keep deployment-repo compose separate and verify after rsync.

## Codex Security supply-chain remediation

### Done

- Reworked CI image publication into a digest-bound sequence: BuildKit stages an
  untagged canonical digest, Trivy scans that digest with `exit-code: 1`, and a
  separate job promotes the same digest to branch/version/SHA/`latest` tags.
- Removed `react-doctor@latest`, global and remote fallbacks. The package script and
  pre-commit now execute only the pnpm-lockfile binary.
- Centralized Gitleaks `v8.30.1` on its immutable multiarch digest, disabled container
  networking in both scanners, and updated the staged hook to the Gitleaks 8 CLI.
- Added a pinned ast-grep structural lint rule, CI/pre-commit gates, and five
  supply-chain contract tests.
